# Changelog

## 1.1.0

First public release of Snippet Palette.

- Dockable snippet panel with wrapping, vertical and horizontal layouts.
- Colored titles, optional icons and a searchable icon picker.
- Search expands only when requested; compact settings with separate edit dialogs.
- Drag handles, insertion indicators and keyboard shortcuts for reordering.
- English and Simplified Chinese UI following Obsidian's language setting.
- Installed version displayed in settings, read directly from the plugin manifest.
- Validated release artifacts built by the Linux, macOS and Windows CI matrix.

Requires Obsidian 1.8.7+. Plugin ID: `snippet-palette`.
